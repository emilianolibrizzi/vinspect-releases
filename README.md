## Key Capabilities

- **DOM & DU Integration** — Structured V1 and V2 visual inspection workflows, official English PDF/HTML reports, QR identification, section progress tracking, comparison, and shared team workspaces.
- **Components Inspection** — Electronic board UPI and family identification, guided front/back photography, continuous capture, perspective crop review, recoverable upload queues, and photographic PDFs.
- **Local Laboratory Server** — Self-contained Linux server manager with local archives, automatic ZIP backups, network and optional Wi-Fi hotspot controls, operator list management, and optional **Protected access** (server password and personal operator PINs).
- **1-Click Signed Updates & 7 Languages** — Built-in Ed25519-verified 1-click updates, optional Google Drive report export, and full multilingual interface (`EN`, `IT`, `FR`, `DE`, `NL`, `EL`, `ES`) while preserving official inspection reports in English.

## Download & Install (KM3NeT Collaboration)

1. Open the **[KM3NeT Download Page](https://emilianolibrizzi.github.io/vinspect-releases/)**, enter the collaboration password, and download **`VInspect-Setup`**.
2. Make the file executable (`chmod +x VInspect-Setup` or *Properties → Permissions → Allow executing*) and open it.
3. Click **Install** (`~/VInspect`), open **VInspect**, and press **Start server**.
