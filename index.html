VInspect

Visual inspection for KM3NeT

Inspection and quality assurance platform for KM3NeT optical modules and electronic components.

Version 1.0.0 · Linux x86_64 · 1-Click automatic updates

Install in 3 steps

  1. Enter the collaboration password and download VInspect-Setup.
  2. Make it executable (right-click → Properties → Permissions → Allow executing, or chmod +x VInspect-Setup) and open it.
  3. Click Install, open VInspect, and press Start server.
