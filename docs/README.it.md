## Funzionalità principali

- **Integrazione DOM e DU** — Flussi strutturati di ispezione visiva V1 e V2, report ufficiali PDF/HTML in inglese, identificazione QR, avanzamento per sezioni, confronto e lavoro condiviso in team.
- **Ispezione Componenti** — Identificazione UPI e famiglia per schede elettroniche, fotografia guidata fronte/retro, scatto continuo, ritaglio prospettico controllato, code di caricamento ripristinabili e PDF fotografici.
- **Server Locale di Laboratorio** — Server manager autonomo per Linux con archivi locali, backup ZIP automatici, gestione rete e hotspot Wi-Fi opzionale, gestione lista operatori e **Accesso protetto** opzionale (password del server e PIN personali operatori).
- **Aggiornamenti Firmati 1-Click e 7 Lingue** — Aggiornamenti automatici 1-click verificati con firma Ed25519, esportazione opzionale su Google Drive e interfaccia completa in 7 lingue (`EN`, `IT`, `FR`, `DE`, `NL`, `EL`, `ES`) mantenendo i report ufficiali in inglese.

## Download e Installazione (Collaborazione KM3NeT)

1. Apri la **[Pagina di Download KM3NeT](https://emilianolibrizzi.github.io/vinspect-releases/)**, inserisci la password della collaborazione e scarica **`VInspect-Setup`**.
2. Rendi il file eseguibile (`chmod +x VInspect-Setup` oppure *Proprietà → Permessi → Consenti esecuzione*) e aprilo.
3. Clicca **Installa** (`~/VInspect`), apri **VInspect** e premi **Avvia server**.
